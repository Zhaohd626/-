# 地面激光测振数据示例

选取车辆荷载作用下的少量混凝土路面振动速度记录，展示地面激光测振数据的格式、读取方式及波形特征。

![导出速度记录](../assets/signals.png)

示例程序包括文本读取、数据完整性检查与波形绘制。在总项目根目录运行：

```bash
python run_demo.py --source ground
```

TXT 文件保留原有数值与记录顺序，使用 `gb18030` 编码，数据列为导出时间（s）和速度（mm/s）。导出时间戳存在重复，波形采用采样点序号展示。具体格式见 [数据说明](DATA.md)，数据索引保留于原有 manifest 中。

本子集仅公开选定记录与基础读取、绘图示例，完整研究数据及专用处理方法保留。
